# LLM Video Lens

動画を、AI（LLM）が読める短い文章と確認用の画像に変えるコマンドラインツールです。ショットに分け、ショットごとに体とカメラがどう動いたかを書き、すべての内容を元のフレーム番号までたどれるように残します。

パッケージ・コマンド・LAN サービスは最初の名前のまま `image_lens`（`image-lens`）です。

## これは何？

人やキャラクターが映る動画を、AI エージェントが扱えるように整理するツールです。動画を 1 本入れると、ショット（カット）ごとに体・腕・脚・カメラの動きを短い文章（`look.md`）に書き、確認用の画像も一緒に作ります。出力ファイルは人が開いて読んでもかまいません。

確かでない部分をでっち上げることはしません。点を見失った区間は「不明」と書き、ツール自身が自信のない区間は先頭の「먼저 확인할 곳」（先に確認する所）にまとめます。

## 主な機能

- **まとめて要約（`look`）**：動画 1 本を、ショットごとの動きの要約 `look.md` と画像に変えます。出力の文章は韓国語です。
- **区間を質問（`at`）**：「18〜22 秒に何が起きた？」のように、4 秒以内の区間の根拠だけを集めます。
- **ショットの分割と一覧（`scan`、`brief`、`catalog`）**：カットの境界を見つけ、ショットごとに元のフレーム範囲と欠けた区間を載せた一覧を作ります。
- **フレームの比較（`compare`、`zoom`）**：2 つのフレームの違いを画像で見たり、短い区間を密なフレームで見たりします。
- **点を自分で置く（`grid`、`mark`）**：小道具や、姿勢モデルが名前を知らない部分に点を置き、名前を付けて追跡します。
- **閉じた作業スペース**：入力と出力は作業スペースのフォルダーの中だけで読み書きします。上書きや、シンボリックリンクを含むパスは拒否します。

## クイックスタート

1. Python 3.11 以上で依存パッケージをインストールします。`look` は姿勢推定と点の追跡を両方使うので、2 つのセットがどちらも必要です。

   ```sh
   pip install -r requirements/pose.txt -r requirements/tracking.txt
   ```

2. モデルファイルを 3 つ自分で用意します。人物検出（YOLOX HumanArt、ONNX）、全身の姿勢（RTMW 133 キーポイント、ONNX）、点の追跡（CoTracker のチェックポイント）です。リポジトリには入っておらず、自動でダウンロードもしません。
3. 作業スペースのフォルダー（既定はリポジトリ内の `workspace/`）に動画をコピーし、`workspace/models.json` にモデルのパスを書きます。

   ```json
   {"detector": "/models/yolox_humanart.onnx", "pose_model": "/models/rtmw133.onnx", "checkpoint": "/models/scaled_offline.pth"}
   ```

4. リポジトリのフォルダーで実行します。下の `W` は作業スペースのフォルダーのパスです。

   ```sh
   python -m image_lens --workspace W look --video clip.mp4 --out look-clip
   ```

5. 出力フォルダーの `look.md` を開きます。先頭の「먼저 확인할 곳」から見てください。

## 使用例

### 動画を 1 本要約して読む

`look.md` は追跡した区間ごとに 1 行です。1 行には次の内容が入ります。

- ショットの構図：全身、膝上、上半身、顔のクローズアップ
- 画面全体（カメラ）と体の中心の動き
- 腕・脚などの部位が体を基準にどう動いたかと、その速さ。例：「속도 9→5→3→1 px/f」
- 点を見失った所、絵が切り替わった所、同じ姿勢の繰り返しなど、読み方の表示

一緒に作られる画像もあります。

- `<window>-onion.jpg`：最初と最後のフレームを重ね、動きを矢印で描いた画像
- `frame-sheet-N.jpg`：動画全体から均等に選んだフレームの一覧
- `check-sheet-N.jpg`：「먼저 확인할 곳」の区間の密なフレーム

### 結果を 1 行読んでみる

1 人で踊る実写動画の `look.md` から 1 行を取り出しました（長いので一部を `…` で省略）。出力の文章は韓国語です。

```text
- 2.16–3.40s f54..84 | 전신 | 정면(사람 왼쪽=화면 오른쪽) | 팔 자세: 왼팔 가슴 높이·오른팔 어깨 높이, 오른팔 몸 가운데 넘어감 → 왼팔 허리 아래·오른팔 가슴 높이, 오른팔 몸 가운데 넘어감 | 전체: 카메라 모름(3%만 맞춤), 몸 관측 끊김·기준점 변경, 전체 이동 모름 | 몸 기준: 왼다리(화면 오른쪽: 발목·무릎·허벅지) 오른쪽 65px → 오른쪽 위 44px → 위 27px, 몸 바깥으로; … | 손-몸: 두 손 모음 2.24–3.16s, 떨어짐; 오른손(화면 왼쪽)이 왼어깨(화면 오른쪽) 가까이 옴 2.40–3.08s, 떨어짐 | …
```

- `2.16–3.40s f54..84`：時間と元のフレーム番号。この番号で元動画をたどれます。
- `전신`（全身）、`정면(사람 왼쪽=화면 오른쪽)`（正面、本人の左＝画面の右）：構図と体の向き。以降の左右は本人の体が基準で、括弧内が画面上の側です。
- `팔 자세`（腕の姿勢）：区間の最初と最後の手首の高さと、手首が体の中心線を越えたかどうか。
- `전체`（全体）：カメラと体の中心の動き。この動画は背景が無地でカメラを測れないため「모름」（不明）と書きます。
- `몸 기준`（体基準）：体の中心の動きを除いた手足の動き。矢印は時間の順です。この行では左脚が右へ出てから上がりました。
- `손-몸`（手と体）：手が反対側の肩に近づいた区間や、両手が合わさった区間。画面上の距離なので「接触の候補」として読みます。

### 気になる区間だけを聞く

要約全体を読み直さず、その区間だけを聞いてください。区間は 4 秒以内です。

```bash
python -m image_lens --workspace W at --look W/look-clip --span 18-22 --out W/at-18-22
```

`at.md` にはその区間にかかる行と表示、開くべき画像の名前が集まり、`at-frames-1.jpg` には密なフレーム 12 枚が入ります。

### 姿勢モデルが知らない部分を追跡する

`grid` で座標の目盛りを描いたフレームを見て、`mark` で点を置いて追跡します。点は最大 8 個まで置け、名前は ASCII で付けます。

```bash
python -m image_lens --workspace W grid --video V --frame 572 --box 100,250,1000,1000 --out W/grid-f572.jpg
python -m image_lens --workspace W mark --video V --shots W/look/shots.json --frame 572 --end 599 --point hammer-stripe=430,680 --point eye=322,738 --checkpoint C --out W/mark-s19
```

## 現在の状態と限界

- 検証した環境は macOS arm64 の Python 3.12 です。Windows での動作とインストールしたパッケージ（wheel）の実行は未検証で、点の追跡には POSIX 環境が必要です。
- 姿勢、動作、同じ人物かどうかの判定、緩急（easing）を正確に当てるとは主張しません。「먼저 확인할 곳」にない区間も間違っていることがあるので、フレームシートも合わせて見てください。
- モデルファイルは自分で用意する必要があります。CoTracker のソースとチェックポイントには非商用の利用条件があり、姿勢モデルの重みのライセンスは確認されていません。
- 1920×1080 より大きい動画は縮小してから処理します。このときレポートの px の値は縮小した動画が基準です。

## AIと一緒に作ったプロジェクト

方向は人が決め、AIエージェントたちが一緒に作ったプロジェクトです。何を作るか、どの精度を目指すか、何を採用するかは人が決め、実装・計測・コードレビューは Claude（Anthropic）と Codex（OpenAI）のエージェントが分担しました。最近の改善案は、作った側からは見えない別保管の正解フレームで別のエージェントが採点してから採用しています。上のバナーもその様子を描いたもので、Claude が映像を読みながら BRIEF に一行ずつ書いていきます。[look ノート](look-notes.md)はその過程でエージェントが残した計測記録です。
